# check_response

Скрипт проверяет, отвечают ли IP-адреса по HTTP. Он показывает, какие адреса работают, за сколько они отвечают и какие нет.

## Быстрый старт

1. Создайте текстовый файл `ips.txt` и впишите адреса, по одному на строку:

   ```
   188.72.103.107
   188.72.110.17
   188.72.111.8
   ```

2. Запустите:

   ```bash
   bash check_response.sh --file ips.txt
   ```

Нужны только `bash` и `curl`. Скрипт работает на Linux, macOS и в Git Bash на Windows.

## Что вы увидите

```
IP              STATUS    HTTP      TIME
--------------------------------------------------------
188.72.103.107  WORKS     204       37 ms
188.72.103.102  FAIL      curl:28   таймаут
--------------------------------------------------------

========================================================
РАБОЧИЕ EDGE — ОТ БЫСТРОГО К МЕДЛЕННОМУ
========================================================
188.72.103.107      0.037412 sec
```

| Колонка | Значение |
|---|---|
| **STATUS** | `WORKS` (зелёный) — адрес ответил, `FAIL` (красный) — ответа нет |
| **HTTP** | Код ответа, например `204`. У `FAIL` — код ошибки |
| **TIME** | Время ответа в мс. У `FAIL` — причина словами |

После таблицы идёт список рабочих адресов от самого быстрого к самому медленному, а в конце итог.

**Частые коды ошибок:** `curl:7` — соединение отклонено, `curl:28` — таймаут, `curl:6` — адрес не найден, `curl:56` — соединение сброшено.

## Параметры

Все параметры необязательные, кроме `--file`.

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `-f`, `--file` | Файл со списком IP | — |
| `-p`, `--port` | Порт | `80` |
| `--path` | Путь запроса | `/generate_204` |
| `-t`, `--timeout` | Сколько секунд ждать ответ | `3` |
| `-j`, `--jobs` | Сколько адресов проверять одновременно | `20` |
| `--https` | Проверять по HTTPS | выключено |
| `--expect КОД` | `WORKS` только при этом коде ответа | любой код |

Примеры:

```bash
bash check_response.sh --file ips.txt --timeout 5
bash check_response.sh --file ips.txt --port 8080 --path /health
bash check_response.sh --file ips.txt --expect 204
```

## Хорошо знать

- Любой HTTP-ответ (204, 200, 404, 503…) считается `WORKS`. Нужен строго определённый код — добавьте `--expect`.
- В файле можно оставлять пустые строки и комментарии после `#`. Повторяющиеся адреса проверяются один раз, а строки, не похожие на IP, пропускаются с предупреждением.
- Код выхода `0` — ответили все, `1` — есть не ответившие. Это удобно для автоматизации.
- Справка: `bash check_response.sh --help`.
